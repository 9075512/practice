# 背题库 · Excel 导入 + 翻卡背诵

一个只做背题的小系统：后台用 Excel 导入题目，移动端按**题库**和**题型**筛选后翻卡背诵。没有章节、分类、知识点、练习记录、错题本、统计报表。

- 后台：Vue 3 + Element Plus，4 个页面（题库、题目、卡密、用户）
- 移动端：零构建原生 H5（`mobile/`），后端同源托管在 `/m/`，底部三 Tab（题库 / 会员 / 我的）
- 服务端：Express 4 + SQLite，零外部服务，`npm start` 即用
- 导入：标准 Excel 模板，支持 5 种题型，自动识别题型、选项与答案
- 账号：用户名 + 密码，**单点登录**（同一账号只允许一台设备在线）
- 会员：卡密激活成为永久 VIP，可设置 VIP 专属题库

详细设计见 [`docs/架构设计.md`](docs/架构设计.md)。

## 功能范围

### 移动端（`/m/`）

`mobile/` 目录是一套零构建的原生 H5（HTML + CSS + ES Module），后端启动后自动托管在 `/m/`：

```bash
cd server && npm run start
# 手机与电脑同一 WiFi 下，浏览器打开 http://<电脑局域网IP>:3000/m/
```

| 页面 | 能力 |
|---|---|
| 题库（Tab） | 展示全部题库、题量、题型分布与已掌握数量，下拉刷新，VIP 锁定标识 |
| 会员（Tab） | 卡密激活（自动整理 16 位格式）、会员权益与激活信息 |
| 我的（Tab） | 昵称编辑、会员状态、修改密码、注册 / 最近登录时间、退出登录 |
| 背诵设置 | 按题型筛选、顺序 / 随机、只看未掌握、继续上次进度、普通 / 背题模式切换 |
| 翻卡背诵 | 普通模式先看题干、点「显示答案」揭示答案与解析；背题模式进入即展开答案与解析，翻页保持展开；上一题 / 下一题；标记掌握 |

「已掌握」和「上次背到第几题」只保存在本机浏览器，不上传服务器。两种模式的进度分开记录：背题模式按「题库 + 题型 + 顺序 + 筛选」单独计位，切模式不会串进度。

桌面浏览器访问会自动居中为手机宽度，方便预览。接口地址默认同源 `/api/mp`；静态页与后端不同源时，改 `mobile/index.html` 里的 `window.APP_CONFIG.apiBase`。

### 账号（用户名 + 密码）

移动端**必须注册账号**才能背题，不存在游客态：

| 场景 | 行为 |
|---|---|
| 未登录 | 只能浏览题库列表；点题库 / 背诵 / 我的 / 会员都会被拦到登录页，登录后自动回到原页面 |
| 注册 | 用户名 3-20 位（中文 / 字母 / 数字 / 下划线）+ 密码 6-32 位，注册即登录 |
| 登录 | 用户名 + 密码，会员与账号绑定，换手机、清缓存都能找回 |
| 退出 | 清掉本地会话并回登录页（会员仍在账号里，重新登录即恢复） |
| 改密 | 「我的」→ 修改密码，需原密码；改密后其他设备自动下线，本机保持登录 |
| 保护 | 密码用 scrypt 加盐哈希存储；同一 IP + 用户名 10 分钟内失败 8 次后限流 10 分钟 |

### 单点登录（唯一在线）

同一个账号只允许一台设备在线，适合按账号售卖会员的场景，避免一码多用：

- 每次登录都会覆盖服务端 `app_user.session_id`，旧设备手上的令牌立刻失效
- 旧设备再发起任何请求都会拿到 `401 / 40110`，前端提示「账号已在其他设备登录」并跳回登录页
- 退出登录会清空会话号，当前令牌同样立即失效
- 修改密码会轮换会话号：其他设备下线，当前设备自动换发新令牌，不用重新登录
- 管理员禁用账号时，已登录的会话也会在下次请求被拦（403）

后台「用户管理」可看到账号列，并按「已注册账号 / 游客」筛选。

### VIP 会员

| 场景 | 行为 |
|---|---|
| 激活 | 输入 16 位卡密（支持小写、带空格、带连字符），成功后成为**永久 VIP**，无到期时间 |
| 重复激活 | 同一张卡重复提交返回成功（幂等），不会产生第二条会员 |
| 已是 VIP | 再输入新卡返回 40913，新卡不会被消耗 |
| 后台设置 | 「用户管理」里可直接把用户设为普通用户 / 永久 VIP，不消耗卡密；取消后卡密不退回 |
| VIP 题库 | 后台可把题库标记为 VIP 专属；非会员可见但锁定，取题返回 403 |
| 异常 | 无效 40410 / 已使用 40910 / 已作废 40911 / 过期 40912 / 限流 42910 |

卡密由后台批量生成（单批 ≤ 2000 张），明文只在生成时显示一次（可复制 / 下载 CSV），服务端只存 HMAC-SHA256 哈希。支持按卡或整批作废未使用卡密。设计细节见 [`docs/卡密VIP会员系统设计.md`](docs/卡密VIP会员系统设计.md)。

### 后台

| 页面 | 能力 |
|---|---|
| 题库管理 | 新建 / 编辑 / 删除题库（含 VIP 专属开关），下载模板，Excel 导入（预览 → 确认），查看题量与题型分布 |
| 题目管理 | 按题库、题型、关键词筛选；查看、编辑、删除单题 |
| 卡密管理 | 批次生成与一次性明文下载、卡密明细与作废、VIP 会员名单 |
| 用户管理 | 用户列表（搜索昵称 / 用户名 / 身份 / ID，按状态、VIP、账号类型筛选）、详情（含激活记录）、改昵称、设置身份（普通用户 / 永久 VIP）、启用 / 禁用（禁用即封禁，恢复后 VIP 自动生效） |

## 快速开始

### 1. 启动后端

```bash
cd server
npm install
npm run start        # http://127.0.0.1:3000
```

首次启动会自动建表并创建管理员，数据库文件为 `server/data/app.db`。

需要示例数据时：

```bash
npm run db:seed      # 写入 3 个示例题库 / 30 道题（已有数据会跳过）
```

### 2. 构建后台（Express 同源托管）

```bash
cd admin
npm install
npm run build        # 输出到 server/public
# 打开 http://127.0.0.1:3000
```

开发态（热更新，端口 5288）：

```bash
cd admin
npm run dev          # http://127.0.0.1:5288
```

管理员账号：`admin / 123456`

### 3. 在线部署（可选）

用「发布为应用」发布 **`server/` 目录**（不是项目根目录），后台、接口、移动端会一起上线：

- 启动命令：`node src/server.js`（不再需要 `ALLOW_DEVICE_LOGIN`，唯一在线由会话号保证）
- 想清空线上用户（例如重新开始）：`node scripts/reset-users.mjs --dry-run` 先看数量，再加 `--yes` 执行；会把用户、会员、激活记录清空并把已用卡密退回未使用
- 移动端改过之后，先在 `server/` 下执行 `npm run sync:mobile`，把仓库根的 `mobile/` 同步成 `server/mobile` 副本（部署只上传 `server/`）
- SQLite 随代码一起上传，因此线上也有题库数据；线上库是副本，本地 `server/data/app.db` 才是主库，本地改数据后需重新发布同步

## Excel 导入

后台「题库管理 → 下载模板」会得到 `背题题库导入模板.xlsx`，包含「题目」与「填写说明」两个工作表。

### 表头（第一行，不可删除）

| 题库 | 题型 | 题干 | 选项A | 选项B | 选项C | 选项D | 答案 | 解析 |
|---|---|---|---|---|---|---|---|---|
| 示例题库 | 单选题 | 题干…… | 甲 | 乙 | 丙 | 丁 | A | 解析文本 |

### 填写规则

- **题库**：名称相同归入同一题库；不存在的题库会自动创建。
- **题型**：支持 `单选题` / `多选题` / `判断题` / `填空题` / `简答题`。留空时按选项和答案自动推断。
- **题干**：必填，最多 5000 字。
- **选项**：按需填 A ~ D（最多支持到 H）。判断题可留空，系统自动补「正确 / 错误」。
- **答案**：必填。单选填 `A`；多选填 `ABD` 或 `A、B、D`；判断题填 `正确 / 错误` 或 `对 / 错`；填空题、简答题直接填文本。
- **解析**：选填，最多 10000 字。
- **重复**：同一题库中「题型 + 题干」完全一致视为重复，导入时自动跳过（忽略空格和常见标点）。
- **限制**：单文件 ≤ 10MB、≤ 20000 行。

导入流程是两段式：上传后先解析并展示「可导入 / 重复 / 异常」统计与前 20 道预览，确认后才写库。异常行会列出行号和原因，不影响其他行导入。

也支持「全部导入指定题库」：忽略表格中的题库列，把所有题目写入一个已存在的题库。

## 数据模型

只有核心业务表：

```
admin_user       管理员账号
bank             题库（名称、简介、排序、vip_only、软删除）
question         题目（题型、题干、选项 JSON、答案、解析、排序、软删除）
app_user         移动端用户（username 唯一；session_id 记录当前唯一在线会话）
card_batch       卡密批次
card_key         卡密（只存哈希 + 末 4 位，状态：unused / used / void）
vip_membership   永久会员（user_id 唯一，无到期时间字段）
card_activation_log  激活审计日志
```

题目直接挂在题库下，题型是题目字段。删除题库会同时软删除其下所有题目。

## 接口

统一响应 `{ code, message, data }`，分页为 `{ list, total, page, pageSize }`。后台鉴权使用 `X-Admin-Token`，移动端使用 `X-User-Token`（均为无状态 HMAC 令牌，用户令牌额外带会话号）。

### 移动端

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/mp/auth/login/password` | 账号密码登录；成功后旧设备的令牌立即失效 |
| POST | `/api/mp/auth/register` | 注册（无需登录态，注册即登录） |
| POST | `/api/mp/auth/logout` | 退出登录（清空会话，当前令牌立即失效） |
| GET / PUT | `/api/mp/me` | 我的资料 / 改昵称 |
| PUT | `/api/mp/me/password` | 修改自己的密码（需原密码），会换发新令牌并踢掉其他设备 |
| GET | `/api/mp/vip/status` | 当前用户 VIP 状态 |
| POST | `/api/mp/vip/activate` | 卡密激活（幂等） |
| GET | `/api/mp/banks` | 题库列表（**无需登录**），VIP 专属题库对非会员标记 `locked` |
| GET | `/api/mp/banks/:id` | 单个题库 |
| POST | `/api/mp/questions/query` | 取题；VIP 题库对非会员返回 403 |

### 后台

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/admin/auth/login` | 登录 |
| GET | `/api/admin/banks` | 题库列表 |
| GET | `/api/admin/banks/options` | 题库下拉选项 |
| POST / PUT / DELETE | `/api/admin/banks[/:id]` | 题库增改删（含 `vipOnly`） |
| GET | `/api/admin/questions` | 题目筛选（题库 / 题型 / 关键词 / 分页） |
| GET / PUT / DELETE | `/api/admin/questions/:id` | 单题查看、编辑、删除 |
| GET | `/api/admin/import/template` | 下载 Excel 模板 |
| POST | `/api/admin/import/preview` | 解析 Excel 并返回预览 |
| POST | `/api/admin/import/commit` | 确认导入 |
| GET / POST | `/api/admin/card-batches` | 批次列表 / 生成（明文仅返回一次） |
| GET | `/api/admin/card-batches/:id` | 批次统计 |
| GET | `/api/admin/card-batches/:id/cards` | 卡密明细（分页，按状态筛选） |
| POST | `/api/admin/card-batches/:id/void` | 整批作废未使用 |
| POST | `/api/admin/cards/:id/void` | 单卡作废 |
| GET | `/api/admin/vip-members` | VIP 会员名单（昵称 / 身份 / 卡密尾号 / 用户 ID 搜索） |
| GET | `/api/admin/users` | 用户列表（搜索 / 状态 / VIP / 账号类型筛选） |
| GET / PUT | `/api/admin/users/:id` | 用户详情（含激活记录）/ 改昵称 |
| POST | `/api/admin/users/:id/status` | 启用 / 禁用用户 |
| POST | `/api/admin/users/:id/vip` | 设置身份：`{"isVip":true}` 开通 / `{"isVip":false}` 取消（不消耗卡密） |

## 常见问题

**端口 3000 被占用**

```bash
PORT=3100 npm run start
```

同时修改 `admin/vite.config.js` 的代理端口。

**老设备突然提示「账号已在其他设备登录」**

这是单点登录的预期行为：同一账号只允许一台设备在线。用最新登录的那台设备继续使用即可；如需在多台设备切换，退出登录后再登录另一台。

**Excel 导入后没有题目**

看预览弹窗里的「异常」列表：常见原因是答案为空、单选题填了多个字母、题型无法识别。修正后重新导入即可，已成功的题目会被识别为重复并跳过。

**能否修改题库里的题目**

可以。题目管理页支持逐题编辑（题型、题干、选项、答案、解析）和删除。批量修改建议改 Excel 后重新导入。

**卡密明文丢了怎么办**

无法找回。服务端只存哈希，明文只在生成弹窗出现一次。丢失后只能作废该批次未使用的卡，重新生成一批。因此 `CARD_SECRET` 环境变量必须备份，一旦更换，所有未使用卡密都会验证失败。

**怎么开通微信登录**

已不支持。小程序端已下线，移动端采用用户名 + 密码注册，不再依赖 `WX_APPID` / `WX_SECRET`。

**旧版数据怎么办**

如果数据库还是旧版（章节 / 分类 / 英文题型），服务启动时会自动迁移：题库按名称保留，题目按中文题型平铺到题库下，章节与分类信息丢弃，不会重复写入。

**better-sqlite3 安装失败**

它是可选依赖，失败会自动回退 Node 内置 `node:sqlite`（需 Node 22.5+），可忽略安装告警。

## 技术说明

- 统一响应 `{ code, message, data }`；时间为 `YYYY-MM-DD HH:MM:SS` 本地时区
- 鉴权：HMAC-SHA256 无状态签名令牌，服务重启不掉登录；管理员与用户令牌分类型签发、不可互用
- 单点登录：用户令牌内嵌 `sid`，与 `app_user.session_id` 比对；登录 / 改密 / 退出都会轮换该值，旧令牌立即失效
- 卡密激活是单个 SQLite 事务：`BEGIN IMMEDIATE` 串行 + `UPDATE ... WHERE status='unused'` 条件更新 + 唯一索引兜底，并发下同一张卡只有一人成功
- 删除一律软删除，题库名称唯一性只约束未删除记录，删除后可用同名重建
- 随机顺序在客户端用 Fisher-Yates 洗牌后整份缓存，翻页不会重复或漏题
- Excel 解析使用 SheetJS；预览结果在服务端缓存 30 分钟，确认时重新校验重复
- 账号密码用 scrypt（N=16384）加盐哈希；`/m/` 静态资源带 `Cache-Control: no-cache` 强制协商，避免手机端沿用旧样式

移动端 H5 兼容红线（老内核不踩这几个坑基本不会「样式错乱」）：

- 输入框字号必须 ≥16px，否则 iOS 聚焦会自动放大整个页面
- 不用 `inset` 简写；`backdrop-filter` / `sticky` / `user-select` 必带 `-webkit-` 前缀
- `env(safe-area-inset-*)` 先给 `0px` 兜底再覆盖，标题栏用 `min-height` 不用死高度
- flex `gap` 必须有 `.no-flex-gap` 的相邻兄弟 margin 回退（`index.html` 内联检测脚本负责打标记）
- `calc(var())` 前先写一条固定值声明，老浏览器整条声明失效时不至于内边距归零
