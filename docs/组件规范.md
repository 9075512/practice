# 练题云组件规范 v1.0

> 配套文件：`docs/ui-spec/tokens.css`（设计令牌）、`docs/ui-spec/components.css`（组件样式）、`docs/ui-spec/index.html`（可视化规范）
> 适用范围：中后台、数据看板、题库与内容管理类 Web 应用
> 命名约定：类名 `ui-` 前缀，修饰符 `--`，状态类 `is-`，不覆盖 Element Plus / Tailwind 的任何类名

---

## 0. 使用方式

### 0.1 引入顺序

```js
// main.js
import './styles/tokens.css';     // 必须先引入：提供全部 --ui-* 变量
import './styles/components.css'; // 组件层：只消费变量，不写死色值
import './styles/app.css';        // 业务样式：只做布局组合
```

### 0.2 三种使用姿势

| 方式 | 做法 | 适用 |
|---|---|---|
| 直接用类名 | `<button class="ui-btn ui-btn--primary">` | 原生 HTML / Vue / React 均可 |
| 包成组件 | 用 Vue/React 封装 `UiButton`，内部仍是这套类名 | 团队协作、需要统一 API |
| 与 Element Plus 共存 | 根容器加 `class="ui-scope"`，复用表格/抽屉的尺寸修正 | 已使用 Element Plus 的项目 |

### 0.3 硬约束

1. 组件样式只引用 `--ui-*` 变量，禁止在 `components.css` 之外重写颜色。
2. 状态通过类名切换（`is-active` / `is-open` / `is-error` / `is-loading`），不写内联 style。
3. 一个组件只承担一件事：卡片不做表格，标签不做按钮。
4. 新增组件先确认现有类名无法组合实现，再扩展本文件。

## 2. 基础组件

### 2.1 按钮 Button

**结构**

```
.ui-btn
├── [icon]            可选图标，14–16px，与文字间距 6px
├── label             2–4 个汉字，动词开头
└── [.ui-spinner]     仅 loading 态出现
```

**变体**

| 变体 | 类名 | 用途 | 一屏数量 |
|---|---|---|---|
| 主按钮 | `ui-btn--primary` | 新建、保存、提交 | ≤ 1 |
| 次按钮 | `ui-btn--default` | 导入、导出、取消 | 不限 |
| 危险按钮 | `ui-btn--danger` | 批量删除、停用 | ≤ 1 |
| 文字按钮 | `ui-btn--text` | 行内查看 / 编辑 / 删除 | 不限 |
| 幽灵按钮 | `ui-btn--ghost` | 浅底上的低权重操作 | 不限 |

**尺寸**

| 尺寸 | 类名 | 高度 | 字号 | 内边距 | 场景 |
|---|---|---|---|---|---|
| 小 | `ui-btn--sm` | 30 | 12 | 0 12 | 表格行内、工具栏 |
| 默认 | — | 36 | 13 | 0 16 | 绝大多数场景 |
| 大 | `ui-btn--lg` | 44 | 14 | 0 22 | 登录页、空态主操作 |

**状态**

| 状态 | 触发 | 视觉 |
|---|---|---|
| hover | 鼠标悬停 | 主按钮变浅蓝 `#5B8BF5`；次按钮描边转主色 |
| active | 按下 | 主按钮加深 `#1D4ED8` |
| focus | 键盘聚焦 | 2px 外描边 `#93B4FA`，offset 2px |
| disabled | `disabled` 或 `.is-disabled` | 主按钮 `#C7D9FD`，次按钮灰底灰字，`cursor: not-allowed` |
| loading | `.is-loading` + `.ui-spinner` | 保留按钮宽度，禁用点击，透明度 0.82 |

**代码**

```html
<!-- 主操作 -->
<button class="ui-btn ui-btn--primary">新建题库</button>

<!-- 次操作 -->
<button class="ui-btn ui-btn--default">导入题目</button>

<!-- 危险操作 -->
<button class="ui-btn ui-btn--danger">批量删除</button>

<!-- 行内文字操作 -->
<button class="ui-link">编辑</button>
<button class="ui-link is-danger">删除</button>

<!-- 加载态 -->
<button class="ui-btn ui-btn--primary is-loading" disabled>
  <span class="ui-spinner"></span>保存中
</button>
```

**规则**

- DO：按钮文案用「动词 + 名词」，如「新建题库」「导出报表」。
- DO：提交类按钮在请求期间进入 loading 并 `disabled`，防止重复提交。
- DON'T：同一行出现两个实心主按钮；「取消」不要用主色。
- DON'T：用图标代替文字作为唯一含义，图标按钮必须有 `aria-label`。

### 2.2 表单 Form

**结构**

```
.ui-field
├── .ui-label（.ui-label__required 必填星号）
├── .ui-input / .ui-textarea / .ui-select
└── .ui-hint 或 .ui-error（二选一，错误优先）
```

**规格**

| 项目 | 数值 |
|---|---|
| 控件高度 | 36px（小号 30px） |
| 圆角 | 8px |
| 内边距 | 0 12px（文本域 8px 12px） |
| 字号 | 13px |
| 标签字号 | 12px，颜色 `#475569`，下间距 6px |
| 聚焦 | 主色描边 + `0 0 0 3px rgba(37,99,235,.12)` |
| 错误 | 红色描边 + `0 0 0 3px rgba(239,68,68,.12)` |
| 字段间距 | 14px |

**代码**

```html
<div class="ui-field">
  <label class="ui-label" for="bank-name">
    题库名称 <em class="ui-label__required">*</em>
  </label>
  <input id="bank-name" class="ui-input" placeholder="例如：教师资格 · 综合素质" />
  <div class="ui-hint">最多 40 个字符，保存后可在移动端看到</div>
</div>

<!-- 错误态 -->
<div class="ui-field is-error">
  <label class="ui-label">所属分类 <em class="ui-label__required">*</em></label>
  <div class="ui-select">请选择分类</div>
  <div class="ui-error">请选择所属分类</div>
</div>

<!-- 带搜索 -->
<div class="ui-search">
  <input class="ui-input" placeholder="搜索题干 / 知识点" />
</div>
```

**校验规则**

1. 失焦校验，输入时清除已有错误（避免边输边报错）。
2. 错误文案紧贴控件下方，12px 红色，不弹 toast。
3. 提交失败时滚动到第一个错误字段并聚焦。
4. 只读用 `disabled`，不要用 `readonly` 冒充禁用态（颜色不一致）。

### 2.3 复选、单选与开关

| 组件 | 类名 | 控件尺寸 | 用途 |
|---|---|---|---|
| 复选框 | `.ui-choice` | 16 × 16，圆角 4 | 多选、批量选择 |
| 单选框 | `.ui-choice--radio` | 16 × 16，圆形 | 互斥选项、答案选择 |
| 开关 | `.ui-switch` | 36 × 20 | 立即生效的布尔状态（上架 / 启用） |

```html
<label class="ui-choice">
  <input type="checkbox" checked />
  <span class="ui-choice__box"></span>
  <span class="ui-choice__label">选项 A</span>
</label>

<label class="ui-choice ui-choice--radio">
  <input type="radio" name="answer" />
  <span class="ui-choice__box"></span>
  <span class="ui-choice__label">选项 B</span>
</label>

<button class="ui-switch is-on" role="switch" aria-checked="true" aria-label="上架状态"></button>
```

规则：开关用于「立即生效」，需要点保存才生效的用复选框；开关旁必须有文字说明当前状态。

### 2.4 标签与状态 Tag / Chip

| 类型 | 类名 | 语义 | 示例 |
|---|---|---|---|
| 题型 | `ui-tag--single` / `--multiple` / `--judge` / `--fill` | 固定四色，全站一致 | 单选题 |
| 难度 | `ui-tag--easy` / `--medium` / `--hard` | 语义色：绿 / 黄 / 红 | 中等 |
| 业务状态 | `ui-chip--success` / `--warning` / `--danger` / `--info` | 带圆点的流程状态 | 已提交 |
| 通用标签 | `ui-tag--neutral` | 分类、知识点 | 教育法律法规 |

```html
<span class="ui-tag ui-tag--single">单选题</span>
<span class="ui-tag ui-tag--multiple">多选题</span>
<span class="ui-chip ui-chip--success"><i class="ui-chip__dot"></i>已提交</span>
<span class="ui-chip ui-chip--neutral"><i class="ui-chip__dot"></i>已下架</span>
```

规则：

- 标签只表达分类，不加点击态、不加关闭按钮（需要删除用 `ui-tag` + 独立关闭按钮）。
- 同一列内标签宽度随内容变化，不强行等宽。
- 颜色含义固定：绿=成功/简单，黄=进行中/中等，红=失败/困难，灰=中性/停用。

```
.ui-card
├── .ui-card__head
```

页头用于列表页与详情页顶部，标题 22px，描述 12px，操作区右对齐；移动端自动换行为上下结构。

### 2.6 指标卡 StatCard

```
.ui-stat
├── .ui-stat__label      12px 灰
├── .ui-stat__value      26px / 700 / 等宽数字
├── .ui-stat__unit       12px 灰
└── .ui-stat__foot       11px，左说明右趋势
```

| 变体 | 用途 |
|---|---|
| 默认 | 普通 KPI（题量、用户数） |
| `.ui-stat--brand` | 唯一的核心指标，渐变蓝底白字，一屏最多 1 个 |

```html
<div class="ui-stat-grid">
  <div class="ui-stat">
    <div class="ui-stat__label">题目总数</div>
    <div class="ui-stat__value">142<span class="ui-stat__unit">道</span></div>
    <div class="ui-stat__foot">
      <span>覆盖 4 个题库</span>
      <span class="ui-stat__trend ui-stat__trend--up">+12</span>
    </div>
  </div>
</div>
```

规则：数字必须用等宽数字（`.ui-num` 或组件内置 `tabular-nums`）；单位比数字小两号且不换行；趋势色只用绿/红，不用品牌蓝。

### 2.7 表格 Toolbar / Table / Pager

```
.ui-card
├── .ui-toolbar（左筛选，右操作）
├── .ui-table-wrap > .ui-table
└── .ui-pager（左统计，右页码）
```

| 项目 | 数值 |
|---|---|
| 表头背景 | `#F8FAFC`，文字 12px `#64748B`，600 |
| 单元格内边距 | 12px 14px（compact 9px 12px） |
| 行分割线 | `#F1F5F9`，1px |
| 行 hover | `#F8FBFF` |
| 数字列 | 右对齐 + 等宽数字 |
| 操作列 | 右对齐，文字按钮，固定最右 |

```html
<section class="ui-card">
  <div class="ui-toolbar">
    <div class="ui-toolbar__left">
      <div class="ui-search"><input class="ui-input" placeholder="搜索题库名称" /></div>
      <select class="ui-select"><option>全部分类</option></select>
    </div>
    <div class="ui-toolbar__right">
      <button class="ui-btn ui-btn--default">导入</button>
      <button class="ui-btn ui-btn--primary">新建题库</button>
    </div>
  </div>

  <div class="ui-table-wrap">
    <table class="ui-table">
      <thead>
        <tr>
          <th>题库</th>
          <th class="ui-table__num">题量</th>
          <th class="ui-table__actions">操作</th>
        </tr>
      </thead>
      <tbody>
        <tr>
          <td>
            <div class="ui-table__strong">教师资格 · 综合素质</div>
            <div class="ui-table__sub">职业资格 · 5 个章节</div>
          </td>
          <td class="ui-table__num">48</td>
          <td class="ui-table__actions">
            <button class="ui-link">编辑</button>
            <button class="ui-link is-danger">删除</button>
          </td>
        </tr>
      </tbody>
    </table>
  </div>

  <div class="ui-pager">
    <span class="ui-pager__info">共 142 条</span>
    <button class="ui-pager__btn" disabled>上一页</button>
    <button class="ui-pager__btn is-active">1</button>
    <button class="ui-pager__btn">2</button>
    <button class="ui-pager__btn">下一页</button>
  </div>
</section>
```

规则：

1. 首列放「主信息 + 副信息」两行，主信息 600 字重，副信息 11px。
2. 超过 5 列时，次要列在 ≤768px 隐藏（`v-if="!isMobile"`），不横向压缩字号。
3. 移动端单元格不换行，超出部分由 `.ui-table-wrap` 横向滚动；首列主信息加 `.ui-table__main`，保留换行并保证 140px 最小宽度。
4. 表格不做纵向滚动，靠分页控制长度。
5. 空数据渲染 `.ui-table__empty`，不要留空白表格。
6. 批量操作在选中后出现在工具栏左侧，显示「已选 N 项」。

### 2.9 提示条 Alert

| 变体 | 用途 |
|---|---|
| 默认（info） | 操作说明、字段提示 |
| `--success` | 保存成功、导入完成 |
| `--warning` | 需注意但可继续（如未上架） |
| `--danger` | 错误、失败、不可逆操作警告 |

用于页面内常驻提示；一次性反馈用 toast，字段级错误用 `.ui-error`。

### 2.11 抽屉与弹窗 Drawer / Modal

| 组件 | 宽度 | 用途 |
|---|---|---|
| 抽屉 | 460px（≤900px 380，≤768px 100%） | 新建 / 编辑表单，字段 ≥ 5 个 |
| 弹窗 | 480px（移动端 calc(100vw - 24px)） | 二次确认、轻量表单 |

```
.ui-drawer
├── .ui-drawer__head（标题 + 关闭）
├── .ui-drawer__body（可滚动）
└── .ui-drawer__foot（取消在左，主操作在右）
```

```html
<div class="ui-mask is-open"></div>
<aside class="ui-drawer is-open" role="dialog" aria-modal="true" aria-label="新建题库">
  <header class="ui-drawer__head">
    <h2 class="ui-drawer__title">新建题库</h2>
    <button class="ui-btn ui-btn--text" aria-label="关闭">✕</button>
  </header>
  <div class="ui-drawer__body"><!-- 表单 --></div>
  <footer class="ui-drawer__foot">
    <button class="ui-btn ui-btn--default">取消</button>
    <button class="ui-btn ui-btn--primary">保存</button>
  </footer>
</aside>
```

规则：

1. 抽屉内表单只有一个主按钮，固定在底部不随内容滚动。
2. 关闭前若有未保存修改，二次确认。
3. 危险操作弹窗的确认按钮用 `ui-btn--danger`，默认焦点在「取消」。
4. 移动端抽屉全屏，禁止左右分栏。

### 2.12 标签页与分段控件

| 标签页 | `.ui-tabs` / `.ui-tab` | 页面级内容切换（详情页的「答题明细 / 统计」） |


## 4. 交互与状态

### 4.1 三态必须齐全

| 状态 | 表现 | 缺失后果 |
|---|---|---|
| loading | 骨架屏 / 局部 spinner | 用户重复点击 |
| empty | `.ui-empty` + 下一步引导 | 误以为加载失败 |
| error | `.ui-alert--danger` + 重试按钮 | 页面白屏无解释 |

### 4.2 反馈时机

| 操作 | 反馈方式 | 时长 |
|---|---|---|
| 保存成功 | toast「已保存」 | 2s 自动消失 |
| 保存失败 | toast + 字段级错误 | 手动关闭 |
| 危险操作 | 弹窗二次确认 | 手动 |
| 批量操作 | 按钮 loading + 结果 toast | 2s |
| 复制 / 导出 | 按钮文案变「已复制」 | 1.5s 恢复 |

### 4.3 防重复与并发

1. 提交类按钮进入 loading 并 `disabled`，直到请求返回。
2. 同一资源的更新请求串行，后发请求覆盖前发结果。
3. 列表筛选变化时取消上一次未完成请求（AbortController / 请求序号比对）。

### 4.4 分页与筛选

- 筛选变化后回到第 1 页。
- 每页条数默认 10 / 20，记住用户选择。
- 筛选条件写入 URL query，便于刷新与分享。
- 移动端分页只保留「上一页 / 页码 / 下一页」，居中排列。

## 5. 可访问性

| 项目 | 要求 |
|---|---|
| 对比度 | 正文 ≥ 4.5:1；12px 辅助文字 ≥ 4.5:1（`#64748B` on `#FFF` = 4.76:1） |
| 焦点 | 所有可交互元素有可见焦点环，禁止 `outline: none` 且不补充 |
| 图标按钮 | 必须带 `aria-label` |
| 开关 | `role="switch"` + `aria-checked` |
| 抽屉 | `role="dialog"` + `aria-modal="true"`，打开后焦点移入，ESC 关闭 |
| 表格 | 表头用 `<th scope="col">`；空态用 `colspan` 合并 |
| 动效 | 尊重 `prefers-reduced-motion`，已内置降级 |
| 字体 | 不锁定 `user-scalable=no`，支持系统字号放大 |

## 6. Element Plus 对照

`tokens.css` 已映射主色、圆角、字体与边框；再加 `class="ui-scope"` 可统一尺寸密度。

| 场景 | Element Plus | 本规范做法 |
|---|---|---|
| 主按钮 | `type="primary"` | 由 `--el-color-primary` 自动映射为 `#2563EB` |
| 表格 | `el-table` | `.ui-scope .el-table th` 统一表头底色与字号 |
| 抽屉 | `el-drawer size="460px"` | 移动端改 `size="100%"`；`.ui-scope` 修正头尾内边距 |
| 表单 | `el-form label-position="top"` | 标签在上，12px；字段间距 14px |
| 分页 | `el-pagination layout="total, prev, pager, next"` | 右对齐，字号 12px |
| 空态 | `el-empty` | 用 `.ui-empty` 替换，保证文案结构一致 |
| 消息 | `ElMessage` | 成功 2s，失败手动关闭 |

## 7. 组件验收清单

新增或修改组件时逐项确认：

- [ ] 只使用 `--ui-*` 变量，无硬编码颜色
- [ ] hover / active / focus / disabled / loading 五态齐全
- [ ] 键盘可达，焦点环可见
- [ ] 390px 下不溢出、不遮挡、不出现横向滚动
- [ ] 空态、错误态有文案与下一步操作
- [ ] 数字使用等宽数字，长文本可截断并有 title
- [ ] 与同页其他组件字号、圆角、间距一致
- [ ] 已在 `index.html` 增加可视化示例
- [ ] 已在本文档补充 API 与使用规则
