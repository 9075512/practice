> 来源：练题系统后台（Vue 3 + Element Plus + ECharts）
> 适用：中后台、数据看板、题库 / 内容管理、列表密集型 Web 应用
> 主题：Light（浅色） · 基准字号 14px · 主色 #2563EB

配套文件：

| 文件 | 用途 |
|---|---|
| `docs/ui-spec/tokens.css` | 全部设计令牌 + 基础类，可直接复制到新项目 |

## 1. 设计原则

| 原则 | 含义 | 落地方式 |
|---|---|---|
| 信息优先 | 先回答“现在怎么样”，再提供操作 | 数据用字号 / 字重建立层级，不依赖大面积色块 |
| 层级克制 | 一个区域只有一个视觉重心 | 单主按钮、单层阴影、分割线优先于边框 |
| 操作可预期 | 相同功能在相同位置 | 主操作在右上，危险操作二次确认，分页 / 空态位置固定 |
| 双端同源 | 不为手机复制第二套页面 | 同一组件按断点收敛列宽、间距与信息密度 |

**颜色预算**：一屏内品牌蓝的实心面积不超过 5%，语义色只出现在状态、图表和关键数字上。

## 4. 组件规范

> 本章描述视觉与交互规则；对应的可复用实现见 `docs/ui-spec/components.css`，逐个组件的结构、变体、尺寸、状态与代码见 `docs/组件规范.md`。类名统一 `ui-` 前缀。

### 4.1 按钮

| 类型 | 背景 | 文字 | 边框 | 使用场景 |
|---|---|---|---|---|
| Primary | `#2563EB` | `#FFFFFF` | 无 | 每个区域唯一主操作 |
| Default | `#FFFFFF` | `#475569` | `#E5E9F2` | 次要操作、取消 |
| Danger | `#FEF2F2` | `#B91C1C` | `#FECACA` | 删除、禁用 |
| Text | 透明 | `#2563EB` | 无 | 行内查看、编辑 |

- 高度：小 30 / 默认 36 / 大 44（登录）
- 圆角 8px，字号 13px，字重 500，左右内边距 16px
- Primary hover `#5B8BF5`，active `#1D4ED8`
- 禁用主按钮：`#BFDBFE` + 白字，不使用降低透明度
- 危险操作必须二次确认；确认按钮可用红色

### 4.2 输入与选择

- 高度 36px，圆角 8px，边框 `#E5E9F2`，背景白色
- 占位符 `#CBD5E1`，正文 13px `#0F172A`
- 聚焦：边框 `#2563EB` + `0 0 0 3px rgba(37,99,235,.12)`
- 错误：边框 `#EF4444` + 下方 12px 红色文案
- 标签在上，字号 12px `#475569`，必填用红色 `*`
- 下拉箭头 6px，颜色 `#94A3B8`

### 4.3 单选、复选、开关

- 单选框 16px 圆形，选中为主色描边 + 8px 实心点
- 复选框 16px，圆角 4px，选中为主色底 + 白色对勾
- 开关 36 × 20px，开启 `#2563EB`，关闭 `#DCDFE6`
- 选项之间间距 ≥ 14px；移动端按钮组允许换行

### 4.4 标签与状态

| 类型 | 结构 | 示例 |
|---|---|---|
| 题型标签 | 圆角 6px，8% 同色底，20% 同色描边，12px 字 | 单选题 / 多选题 / 判断题 / 填空题 |
| 知识点标签 | 同上，颜色由后台配置 | 职业理念、教育法律法规 |
| 状态胶囊 | 圆角 999px，浅底深字，11.5px | 已提交 / 进行中 / 已禁用 |
| 难度 | 胶囊，成功 / 警告 / 错误色 | 简单 / 中等 / 困难 |

标签只表达分类，不承担点击；可点击的筛选项使用 Chip 或 Tabs。

### 4.5 KPI 卡片

- 14px 圆角，白底，1px 边框，`--ui-shadow-card`
- 内边距 17 / 18 / 15
- 标签 12.5px `#64748B`
- 数值 27px / 700，字距 -0.6px；单位 12px `#94A3B8`
- 提示 11.5px `#94A3B8`
- 右上角 30px 图标块，圆角 9px，按语义取色
- 右下角可用 4.5% 透明度色块做装饰，不承载信息

### 4.6 面板与卡片

- 背景 `#FFFFFF`，边框 `#E5E9F2`，圆角 14px，`--ui-shadow-card`
- 头部：标题 15px / 650，副标题 12px `#94A3B8`，内边距 18 20 0
- 内容：内边距 16–20px
- 卡片之间间距 14px
- 同一页面不叠加第二层阴影

### 4.7 表格

| 属性 | 规格 |
|---|---|
| 表头 | 背景 `#F8FAFC`，文字 `#475569`，11.5px / 600 |
| 行 | 正文 13px `#475569`，主体列 600 `#0F172A` |
| 行分割 | 1px `#F1F5F9` |
| 行悬停 | `#F8FBFF` |
| 单元格 | 左右 6–12px，上下 10–12px |
| 操作列 | 右对齐，固定在右侧（桌面） |
| 空态 | 居中，58px 圆环 + 12.5px 文案 |

**列优先级**：主体 → 关键指标 → 状态 → 时间 → 操作。手机端只保留前三类中的 2–3 个。

### 4.8 分页

- 右对齐（桌面）/ 居中（手机）
- 按钮 28 × 28px，圆角 7px
- 当前页主色底白字，其余 `#F1F5F9` 底 `#475569` 字
- 显示总数；手机隐藏每页条数选择

### 4.9 抽屉与弹窗

| 类型 | 宽度 | 场景 |
|---|---|---|
| 抽屉 | 桌面 440–720px；手机 100% | 新建 / 编辑实体 |
| 弹窗 | 桌面 480–780px；手机 92% | 确认、短表单、批量导入 |

- 抽屉头部 14–18px 内边距，底部操作固定
- 弹窗距顶 5–6vh，圆角 14px
- 遮罩 `rgba(15,23,42,.42)`
- 关闭方式：右上角 ×、遮罩点击（抽屉）、Esc

### 4.10 空态

- 58–92px 圆环图形（`#E2E8F0` + `#BFDBFE` 高亮）
- 文案 12.5px `#94A3B8`
- 必须提供下一步操作（文字按钮或描边按钮）
- 不使用插画堆叠，保持轻量

## 7. 可用性与可访问性

| 检查项 | 要求 |
|---|---|
| 主文字对比度 | `#0F172A` on `#FFFFFF` ≈ 17.9:1（AAA） |
| 辅助文字对比度 | `#64748B` on `#FFFFFF` ≈ 4.8:1（AA） |
| 主按钮 | 白字 on `#2563EB` ≈ 5.2:1（AA） |
| 弱提示 | `#94A3B8` 仅用于非关键信息，不用于正文 |
| 焦点可见 | 主色描边 + 3px 柔光环，不可 `outline: none` |
| 状态表达 | 颜色 + 文案双重编码，不只靠颜色 |
| 动效 | 0.2s；支持 `prefers-reduced-motion` |
| 触控 | 移动端 ≥ 44 × 44px |
| 表单错误 | 字段级提示，不用弹窗 |

## 8. 工程接入

### 8.1 原生 CSS / Vue / React

```bash
# 1. 复制两个文件到项目
src/styles/tokens.css
src/styles/components.css

# 2. 入口按顺序引入
import './styles/tokens.css';      // 变量层
import './styles/components.css';  // 组件层（ui- 前缀）
import './styles/app.css';         // 业务层
```

```html
<!-- 3. 直接用类名，无需组件库 -->
<button class="ui-btn ui-btn--primary">新建题库</button>
```

```css
/* 4. 业务样式只引用变量 */
.panel {
  background: var(--ui-surface);
  border: 1px solid var(--ui-border);
  border-radius: var(--ui-radius-lg);
  box-shadow: var(--ui-shadow-card);
}
```

### 8.2 Element Plus

`tokens.css` 已包含 Element Plus 变量映射，无需额外配置：

```css
--el-color-primary: var(--ui-brand-600);
--el-border-radius-base: var(--ui-radius-sm);
--el-font-family: var(--ui-font-sans);
```

如使用按需引入，确保 `tokens.css` 在 Element Plus 样式之后加载。

### 8.4 使用约束

1. 颜色、圆角、阴影、间距必须引用 `--ui-*`，禁止业务代码写死 hex。
2. 不新增中间圆角（如 12px），使用 10 / 14 / 18 三档。
3. 一个页面不超过 2 种阴影、3 种字号层级、1 个主按钮。
4. 语义色不用于大面积背景；主色不用于正文。
5. 新增业务色（题型、等级）先在 `tokens.css` 注册，再在组件引用。
6. 响应式只改列、宽、间距，不复制第二套页面。
